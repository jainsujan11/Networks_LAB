I) Data Structures used:

    1) window
        a) int slots[256]:
            - for send window:
                -1: not sent OR sent and acked
                i: sent but not acked, ith message in send buffer for send window
            - for recv window:
                -1: not expected
                i: expected, ith message in recv buffer for recv window 
        b) int window_size: size of window
        c) int start_seq: start sequence number of window

    2) SM_entry (entry for the shared memory table for KTP sockets)
        a) int available: whether the KTP socket is free or allotted
        b) pid_t process_id: process id of the process that created the KTP socket
        c) int udp_fd: mapping from the KTP socket i to the corresponding UDP socket ID
        d) char dest_ip[16]: IP address of the other end of the KTP socket (assuming IPv4)
        e) uint16_t dest_port: port number of the other end of the KTP socket
        f) char send_buf[10][512]: send buffer for the KTP socket
        g) int send_buf_sz: size of send buffer
        h) int send_msg_length[10]: length of the ith message in send buffer
        i) char recv_buf[10][512]: recv buffer for the KTP socket
        j) int recv_read_index: pointer to the next location in recv_buf for application to read from
        k) int recv_valid[10]: whether the ith message in recv buffer is valid or not
        l) int recv_msg_length[10]: length of the ith message in recv buffer
        m) struct wndw swnd: send window for the KTP socket
        n) struct wndw rwnd: recv window for the KTP socket
        o) int nospace: whether receive buffer is full or not
        p) time_t last_sent[256]: time at which message with ith sequence number was last sent (-1 if never sent in the past)
        q) int transmission_cnt: stores the count of messages the sender sent 

    3) KTP_INFO (as specified in problem statement)
        a) int ktp_fd: stores udp socket id
        b) char local_ip[16]: stores ip address
        c) uint16_t local_port: stores port number
        d) int error: stores error number

II) Functions:
    
        1) int k_socket(int domain, int type, int protocol):
            - determines if there is room in the shared memory table for a new KTP socket; 
                if so, it takes the first available entry and adds the new KTP socket's information (obtained via the initsocket.c main function) to them; 
            - returns the KTP socket id upon success and -1 upon failure.
    
        2) int k_bind(int sock_index, char local_ip[], uint16_t local_port,
             char remote_ip[], uint16_t remote_port);
                adds information about the destination (*the term 'destination' is used loosely, meaning the other end of the connection) 
                and binds the KTP socket with the src IP address and src port number. 
                The shared memory table's IP address and port number return 0 in the event of success and -1 in the event of failure.

    
        3) ssize_t k_sendto(int sock_index, const void *buffer, size_t length, int flags,
                   const struct sockaddr *dest_addr, socklen_t addrlen):
            writes the message to the sender side message buffer if the destination IP/Port matches with the bounded IP/Port as set through k_bind()
            returns 0 on success and -1 on failure (along with relevant error codes like ENOBUFS, ENOTCONN, etc.)
    
        4) ssize_t k_recvfrom(int sock_index, void *buffer, size_t length, int flags,
                     struct sockaddr *src_addr, socklen_t *addrlen):
            - looks up the receiver-side message buffer to see if any message is already received.
            - If yes, it returns the first message (in-order) and deletes that message from the table.
            - If not, it returns with -1 and sets a global error variable to ENOMSG, indicating no message has been available in the message buffer.
            - non-blocking.
    
        5) int k_close(int sock_index):
            - marks the corresponding entry in the shared memory table as free
        
        6) void *R():
            - receiver thread function, runs in a loop and does whats stated below
            - waits on all sockets in use using select call, with timeout T
            - if select call returns 0 (timeout)
                - calls FD_SET for each socket in use
                - if nospace flag was set and receiver window is not full, unset nospace flag
                - send ack for last received in-order message so that no deadlock kind situation occurs 
            - if select call returns value > 0
                - for each socket in use
                    - if data message is received
                        - if message is in-order, write to recv buffer and send ack
                        - if message is out-of-order and is within receiver window, write it to recv buffer 
                    - if ack received, update send window and lastSendTime for the corresponding message
                    - duplicates are discarded in case of both message and ack
                    - if recv window is full, set buffer_full flag
                    - the receive window size is piggybacked with the ack message

        7) void *S():
            - sender thread function, runs in a loop, sleeps for T/2, and does whats stated below
            - for the sockets in use, checks if timeout has occured for any message
                - if yes, send all messages in its send window which are valid 
                - if no, check send window for messages not sent yet and send them
            

        8) main function of initsocket.c:
            - responsible for creating and initialising shared memory table, semaphores, etc.
            - has a while loop that uses k_socket and k_bind functions.
